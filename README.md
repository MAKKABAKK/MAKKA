## 关于项目

**小肖同学的小木屋** 是一个基于 HTML、CSS 和 JavaScript 构建的个人博客网站。网站包含了个人介绍、旅行相册、博客文章、项目展示和联系方式等功能模块。

## 使用说明

### 本地运行

1. 克隆仓库到本地：
```bash
git clone https://github.com/MAKKABAKK/makka-blog.git
```

2. 进入项目目录：
```bash
cd makka-blog
```

3. 使用本地服务器打开（推荐）：
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx http-server
```

4. 在浏览器中访问：
```
http://localhost:8000
```
